# English translation audit

The repository is not fully English yet. The audit excludes `web/vendor/three.module.js` because it is third-party code, and excludes binary/generated training artifacts from text translation.

## Findings

1. **HIGH — Browser-facing Spanish copy remains in the web app.**
   Files: `web/index.html`, `web/src/main.js`.
   Scope: page metadata, headings, buttons, controls, labels, status messages, accessibility labels, terrain names, mission copy, audio warnings, and footer text.
   Action: translate all user-visible and accessibility-facing strings to natural English while preserving the existing meaning and UI behavior.
   Rule: R-02, R-16, C-2.

2. **HIGH — Runtime and command-line messages remain in Spanish.**
   Files: `agents.py`, `brain.py`, `collect_experiences.py`, `dqn_agent.py`, `episode_runner.py`, `evaluate.py`, `evaluate_ppo.py`, `experience_store.py`, `inspect_brain.py`, `play.py`, `play_log.py`, `plot_metrics.py`, `ppo_agent.py`, `recovery_curriculum.py`, `replay_buffer.py`, `rocket.py`, `train.py`, and `train_ppo.py`.
   Scope: docstrings, comments, `argparse` help text, validation errors, progress output, model-selection prompts, and metric labels.
   Action: translate the text only; preserve command-line flags, serialized keys, outcome values, model formats, and physics behavior.
   Rule: R-02, R-16, C-4.

3. **MEDIUM — Project documentation is primarily Spanish.**
   Files: `README.md` and `presentacion-rocket-ml/index.html`.
   Scope: setup instructions, controls, physics explanation, training notes, presentation copy, and metadata.
   Action: translate the documentation and presentation text to English, preserving commands, paths, API names, numeric values, and technical claims.
   Rule: R-02, R-16, C-5.

4. **MEDIUM — Test descriptions and test-facing messages contain Spanish.**
   Files: `tests/test_dqn.py`, `tests/test_experiences.py`, `tests/test_play_log.py`, `tests/test_ppo_observations.py`, `tests/test_recovery_curriculum.py`, `tests/test_rocket.py`, and related test modules found by the audit.
   Scope: comments, test names, assertion messages, and any human-readable fixture text.
   Action: translate human-readable text without changing test semantics or stable data values.
   Rule: R-02, C-4.

5. **LOW — Third-party and generated artifacts should remain untouched.**
   Files: `web/vendor/three.module.js`, model checkpoints, audio, CSV metrics, SVG outputs, and cached bytecode.
   Scope: these files may contain English, Spanish, or binary data, but translating them would either modify third-party code or invalidate generated artifacts.
   Action: leave them unchanged; translate the source and documentation that produces or describes them.
   Rule: C-4, C-5.
